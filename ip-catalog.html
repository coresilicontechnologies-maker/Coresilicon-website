Licensing a core

Every license includes the RTL source, a UVM or directed testbench, a datasheet covering registers and timing, and a fixed window of integration support from our engineers. We license per-project or per-site depending on how the core will be used.

If a core in the catalog needs modification — a different data width, an added mode, a different bus interface — that's scoped as a custom variant rather than a from-scratch design, which usually keeps turnaround short.
